Temas de mi formación

¿Qué es HTML?

HTML es un lenguaje de marcado que permite organizar el contenido de una página web mediante títulos, párrafos, imágenes, enlaces y formularios.

¿Para qué sirve CSS?

CSS permite definir la apariencia de una página web, incluyendo los colores, los espacios, los tamaños y la distribución de sus elementos.

¿Qué es Bootstrap?

Bootstrap es un framework que ofrece componentes y clases para facilitar la creación de interfaces web adaptables a diferentes tamaños de pantalla.

¿Para qué sirven Git y GitHub?

Git permite llevar un historial de los cambios realizados en un proyecto. GitHub permite alojar repositorios y colaborar con otras personas.
